# Example files

| File | Description |
|---|---|
| `musicbox/` | **Redstone Music Box (generic framework datapack)**: enchanted jukebox + song menu + lyrics + per-dimension playback ban, **containing no songs at all**. Songs are registered with `scripts/add_to_musicbox.py` |
| `demo.mid` | 8-bar sample MIDI (120 BPM, lead melody + bass + drums). Used to quickly exercise the whole toolchain, and it is also the fixture for `tests/smoke_test.py`: it deliberately contains a two-note chord on one tick and a 1-game-tick snare flam (which produces adjacent note ticks, landing exactly on the "2-wide leaf goes silent" trap). Generated by `tests/gen_demo_midi.py` |
| `song.example.json` | Minimal song.json example (generate.py's input format) |
| `RedstoneMusicBox-v3.zip` | The matching **finished** datapack (historical deliverable): Redstone Music Box v3, 12 songs + jukebox player + lyrics + per-dimension playback ban, compatible with 1.21.2–1.21.8 / 26.2. `musicbox/` is the result of extracting it into a "song-free generic framework" |

## Try the sample MIDI first (zero dependencies)

```bash
python3 scripts/scan_midi.py examples/demo.mid
python3 scripts/midi_to_song.py examples/demo.mid -o /tmp/demo.song.json --name demo --song-id 1
python3 scripts/render_preview.py /tmp/demo.song.json -o /tmp/demo.wav
python3 scripts/make_datapack.py /tmp/demo.song.json -o /tmp/demo-pack --mc-version 26.2
```

## Then try the Redstone Music Box

```bash
cp -r examples/musicbox/datapack /tmp/box          # take a copy to edit
python3 scripts/add_to_musicbox.py --box /tmp/box --song examples/demo.mid --name "example song"
python3 scripts/check_refs.py /tmp/box             # static checks: function references / JSON / line endings
# drop /tmp/box into the world's datapacks/ → /reload → /trigger menu
```

> About the two example datapacks that are no longer shipped with the repo: `datapack_demo` (the first
> 16.5s of Dystopia) and `datapack_m3` (one complete song) were removed on request, and the repo examples
> are now the **song-free generic framework**. They were historical artifacts produced by the pre-fix
> generator (2-wide leaves); they still behave correctly, but `datapack_demo` has 54 notes firing
> 1 game tick early. If you want a reference for "what the generated output looks like", generate one live
> with the commands above (`generate.py` is the fixed version).

The complete finished datapack (Redstone Music Box v2, 11 songs) is not distributed with the skill repo; see the matching release page for how to get it.
